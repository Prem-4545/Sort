# Sort Repository

A comprehensive collection of Java programs featuring various sorting algorithms, number operations, and fundamental programming concepts.

## 📚 Projects Included

### Sorting Algorithms
- **Sort.java** - Implementation of sorting algorithms

### Number Programs
- **Armstrong.java** - Check if a number is an Armstrong number
- **PrimeCheck.java** - Check if a number is prime
- **PrimeCount.java** - Count prime numbers in a range
- **StrongNumber.java** - Check if a number is a strong number
- **MagicNumber.java** - Check if a number is a magic number
- **Factorial.java** - Calculate factorial of a number
- **BinaryCheck.java** - Binary number operations

### String & Character Programs
- **ASCII.java** - ASCII character operations
- **Unicodeall.java** - Unicode character handling
- **Unicodealls.java** - Extended Unicode operations

### Core Java Concepts
- **Loop.java** - Loop demonstrations
- **Demo.java** - General demonstrations
- **Inheritance.java** - Single inheritance examples
- **Inheritance1.java** - Advanced inheritance concepts
- **NestedClass.java** - Nested class implementations
- **Inner2.java** - Inner class examples

### Additional Files
- **sample.java, second.java** - Sample programs
- **sample.c, test.c** - C language samples

## 🛠️ Technologies Used

- **Java** - Primary language
- **C** - Supporting language for some utilities

## 📋 Prerequisites

- Java 8 or higher
- GCC (for C files)
- Any text editor or IDE (VS Code, IntelliJ IDEA, Eclipse)

## 🚀 How to Use

### Compile Java Programs
```bash
javac FileName.java
```

### Run Java Programs
```bash
java FileName
```

### Example
```bash
# Compile
javac PrimeCheck.java

# Run
java PrimeCheck
```
